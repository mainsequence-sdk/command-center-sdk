# Hello Widget Usage Guidance

## Build purpose

Show a configurable greeting while validating an external widget package and deployment setup.

## When to use

- Use as the smallest starting point for a trusted native widget package.
- Use to validate preview, manifest, registry, and deployment composition behavior.

## When not to use

- Do not use this local-UI example for backend execution or privileged data access.

## Authoring steps

1. Choose a globally unique widget and extension id.
2. Replace the example package provenance.
3. Add the package to an operator-reviewed deployment composition.
